P2S high-quality website image assets

This archive contains full-resolution WebP replacements for every image used in the website assets/ folder. Each file keeps its existing .webp filename and original source pixel dimensions, so the site HTML does not need to change.

To use them, replace the corresponding files in the P2S repository's assets/ folder with the files in this archive's assets/ folder, then let GitHub Actions redeploy the site. Keep the same filenames.

The service triptych is restored to its original 1942 x 809 pixels. The square artwork and program images retain their original source dimensions (mostly 1024 x 1024). The images are exported at WebP quality 95.
